# phasync-ext

phasync-ext has moved into [phasync/phasync](https://github.com/phasync/phasync). The prebuilt
binaries ship inside the phasync release packages, under `ext/`, together with their licence.

```bash
composer require phasync/phasync
```

Enable the extension by adding this to your `composer.json`:

```json
{
    "extra": {"phasync": {"ext": true}}
}
```

Questions and bug reports: [phasync/phasync issues](https://github.com/phasync/phasync/issues).

This repository is closed and holds no source or releases.
